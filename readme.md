# Overview

As a software engineering student, I am building a strong foundation in programming, version control, and software development workflows. This project helped me practice creating a simple application, managing files with Git, and publishing code to GitHub.

This software is a simple “Hello World” program written in C#. The program displays a greeting message in the console.

The purpose of creating this software is to confirm that my development environment is properly configured and to practice the complete software development process, including coding, documentation, version control, and publishing a project online.
